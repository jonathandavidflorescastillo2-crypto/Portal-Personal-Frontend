
# Portal Personal Frontend

## Descripción
Proyecto desarrollado para la asignatura Diseño de Sistemas en Internet.

Consiste en una página web personal creada con HTML5 y CSS3, que presenta información sobre el estudiante, sus intereses, habilidades y enlaces a sitios favoritos.

## Tecnologías utilizadas
- HTML5
- CSS3
- Visual Studio Code

## Características
- Encabezado de presentación.
- Sección de información personal.
- Lista de intereses y habilidades.
- Imagen de perfil.
- Enlaces a redes sociales.
- Diseño moderno y adaptable.

## Cómo ejecutar el proyecto
1. Descargar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo index.html en un navegador web.
